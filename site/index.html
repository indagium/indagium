Supported log formats

Indagium detects formats from file contents. Use a built-in profile or define how your own logs turn into columns and records. Explore the multi-format viewer and profile setup.

JSON log viewer

Read newline-delimited JSON (JSON Lines, NDJSON, or JSONL), JSON arrays and objects, and supported documents with metadata. Expand nested fields and multiline messages. Built-in profiles read Pino logs, Docker json-file logs, and systemd journal JSON exports.

CSV log viewer

Open CSV or TSV logs and choose the delimiter and whether the file has a header. Map columns to timestamps, levels, and messages, and display extra fields such as request ID or duration. Preview the mapping against the original file and save it for reuse.

Syslog viewer and Linux logs

Open RFC 5424 and RFC 3164 syslog files, Kubernetes CRI container logs, and Linux dmesg output. dmesg timestamps retain their seconds-since-boot meaning.

Apache, Nginx, and text logs

Read Apache or Nginx access logs in Common or Combined format with fields such as HTTP status and response size. Open logfmt and Go slog text as structured records, or read plain-text logs one line at a time.

Android logcat and automotive DLT

Open Android logcat files and adb bug reports, or inspect DLT captures and exports with separate ECU, APID, and CTID columns.

Custom log format profiles

In Settings › Reading logs › Log formats, map your JSON keys or CSV columns, or build a regex parser from a sample line. Choose which fields appear as columns, then save the profile and export it to share. See the custom profile walkthrough.
