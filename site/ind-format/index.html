Android device capture / Archive formats

Indagium Compact (.ind)

Compact is an experimental Indagium capture archive for keeping the log, optional screen video, notes, markers, screenshots, and synchronization metadata together. It losslessly compresses log data and can use AV1 video when that makes the video smaller. Open the archive in Indagium to continue the investigation.

One capture archive / linked evidence

Keep the log and its context together.

An Indagium Compact archive uses the same capture contents and synchronization metadata as a ZIP export, with compact-specific compression choices. Depending on what was captured and selected, it can include the log, optional screen video, notes, markers, screenshots, and timing metadata that links the available video to the log.

LOG

Lossless log compression

The zstd compression library is included in Indagium; no separate installation is needed. If Indagium cannot load its bundled native library on this computer, the log uses DEFLATE, the standard ZIP compression method.

VIDEO

AV1 only when it saves space

Converting video to AV1 is lossy and can take extra time and working space. Compact uses that conversion only when the result is smaller. Video already in AV1 is copied; if conversion is unavailable or would not make the video smaller, the original video is kept.

Save / open / export

Choose the archive at the point of use.

01 · SAVE

Choose ZIP or Compact

In Save snapshot, use the Format section to choose ZIP or Indagium Compact (.ind); ZIP is selected by default. For a stopped or retained capture, use Save Compact to save the complete session.

02 · OPEN

Open the archive in Indagium

Choose Open in Indagium or drag and drop the .ind file onto the app. The log, available video, and capture metadata open together for review.

03 · EXPORT

Extract the files you need

From an opened capture, choose Export → Export capture range… to choose an archive output for a time range or extract all files to a folder, the plain .log, or the video as stored. Extraction always copies from the whole archive, turns off the time-range controls, and does not convert video.

04 · ATTACH

Work around extension filters

Some attachment services reject the .ind extension. Choose ZIP instead, or place the .ind file inside a ZIP archive before attaching it.

Questions

Compact, answered.

What is Indagium Compact (.ind)?

It is an experimental capture archive for Indagium. It can contain losslessly compressed log data, optional recorded video, notes, markers, screenshots, and synchronization metadata, and is intended to be opened in Indagium.

Does Indagium Compact convert the video?

When video is included, AV1 conversion is lossy and can take extra time and working space. Indagium uses the converted video only when it is smaller, copies video that is already AV1, and keeps the original video when AV1 would not make it smaller or the encoder is unavailable.

Why choose ZIP instead of Compact?

ZIP is the default and uses standard compression methods for broader compatibility with archive tools. Compact targets a smaller archive for opening in Indagium.

Do I need to install zstd?

No. The zstd compression library is bundled with Indagium's desktop app, so nothing needs to be installed on the Android device or separately on the computer. If the bundled native library cannot load on the computer, Compact stores the log with DEFLATE instead.

How do I open or extract a Compact capture?

Use Open in Indagium or drag the .ind file onto the app. From an opened capture, choose Export → Export capture range… to choose an archive output for a time range or extract all files, the plain log, or the video as stored. Extraction always copies from the whole archive, turns off the time-range controls, and does not convert the video.

What if an attachment service rejects the .ind extension?

Choose ZIP for the capture, or place the .ind file inside a ZIP archive before attaching it to a service that rejects the .ind extension.
