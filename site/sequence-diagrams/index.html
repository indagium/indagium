THE WORKFLOW

  1. Choose the scope. Start with an inclusive selection of log rows or the current filtered view.
  2. Review the participants. Enable tags as lifelines, rename or merge them, and add actors when a person or external service belongs in the interaction.
  3. Edit the messages. Use the queue and canvas together to adjust endpoints, labels, grouping, visibility, and presentation.
  4. Keep the evidence attached. Inspect the source rows behind an interaction, save the workspace as a draft, and attach a diagram snapshot or export its Mermaid or PlantUML source.

Hovering a queue row highlights its arrow, and selecting an arrow reveals the corresponding row. Use the canvas to adjust declared lifeline endpoints or pan and zoom.

Read the diagram with care

Let the log set the limits.

A sequence diagram is a way to inspect event order and supported relationships. It does not turn every nearby log line into proof of a call.

Indagium starts from the selected evidence and uses conservative signals for inferred targets, such as validated adjacent thread handoffs and shared high-confidence request or trace identifiers. A message without a supported destination remains unresolved for you to inspect. Direct source calls are enriched only when the source index can verify them; ambiguous matches are surfaced instead of guessed.

The diagram generator runs locally in the desktop app and does not require an external AI service. You can edit the starting diagram, retain its row evidence, and review the resulting PNG snapshot or text source with your analysis note.

Common questions

Sequence diagram generation, answered.

Can I make a sequence diagram from only part of a log?

Yes. Select a non-empty range of rows to use that inclusive range, or create a diagram from the current filtered view.

Can I edit a generated sequence diagram?

Yes. The workspace lets you edit lifelines, actors, message endpoints and labels, grouping, visibility, and presentation. The initial diagram is a starting point for review.

How does Indagium choose message targets?

It uses supported evidence such as adjacent thread handoffs and shared high-confidence request or trace identifiers. When a target is not supported, the message is marked as needing a target instead of being assigned a guessed lifeline.

Can I export the diagram?

Attach an image snapshot to Notes, or use Mermaid or PlantUML source when a text-based review artifact is more useful. You can also save a workspace and reopen it as a draft.

Does sequence diagram generation need an AI service?

No. The diagram generator runs locally in Indagium and does not require an external AI service.
