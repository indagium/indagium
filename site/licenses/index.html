Project / Third-party software

Third-party licences and notices.

Indagium includes open-source Java and native components under their own licences. This page summarizes the bundled media and application libraries and points to the full notices, legal texts, and pinned source inputs. New official binaries that include the Indagium EULA use that agreement; public source remains under PolyForm. Third-party terms govern their components independently and prevail over conflicting application terms. Earlier binaries retain their original terms.

Media and compression / bundled components

The playback and capture stack, with its terms.

The media layer uses JavaCV and JavaCPP bindings with FFmpeg 8.0.1-1.5.13. The inspected FFmpeg classifiers are shared LGPL 3.0-or-later builds configured with version 3 features and without --enable-gpl or --enable-nonfree. The linked codec and runtime components carry their own licences and notices.

Source inputs / pinned and verifiable

Prepare the matching source archive.

The repository records source archives, recipe trees, patches, platform configuration evidence, legal texts, and checksums for the inspected classifiers. Run ./gradlew prepareMediaSources prepareApplicationSources in a checkout to validate these inputs and produce the archive, SHA-256 file, and manifest under build/.

New official releases must provide both Indagium-<version>-media-sources.tar.gz and Indagium-<version>-application-sources.tar.gz, checksums and manifests alongside their installers. Obtain the exact version from the release downloads without accepting the EULA or paying. The application archive includes Java-library sources and complete matching JVM source/build materials. These archives do not claim bit-for-bit reproducibility or patent clearance; historical missing source assets remain a separate issue.
