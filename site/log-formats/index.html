Multi-format log viewer with custom profiles

Open JSON, CSV, syslog, Android logcat, and automotive DLT in a free desktop app for macOS, Windows, and Linux. Browse the supported log formats or choose how your own logs turn into columns and records.

Supported log formats

JSON and application logs

JSON Lines (NDJSON or JSONL), pretty-printed JSON objects, arrays of events, JSON with metadata and nested sections, and Pino JSON. The logfmt profile also reads Go slog text.

System and container logs

Syslog RFC 5424 and RFC 3164, systemd journal JSON exports, Linux dmesg with boot-relative timestamps, Docker json-file, and Kubernetes CRI container logs.

HTTP access logs and plain text

Apache and Nginx HTTP access logs in Common or Combined format. Plain-text logs can be read one non-empty line at a time.

Android logcat and automotive DLT

Android logcat in threadtime, time, brief, and bare formats. The DLT viewer opens binary .dlt captures and raw DLT v1 streams, along with DLT Viewer text and CSV exports.

CSV, TSV, and custom text formats

Use a custom profile to map CSV or TSV columns, assign your own JSON keys, or parse a text layout with a regex.

Bug reports and capture archives

Open Android bug report archives (.zip and .7z) and reopen Indagium captures saved as ZIP or Compact (.ind).

Open and inspect JSON logs

Open a JSON, JSON Lines, or NDJSON file and Indagium detects its format from the contents. The JSON Lines profile reads one event per line, pretty-printed objects, and arrays of events. Built-in profiles also recognize Pino, Docker json-file, and systemd journal JSON.

Inspect one event at a time

Select a row to see nested fields in Message details, or expand the row in the log. In the example above, the request ID and duration stay together under request.

Check how a file was parsed

Right-click the tab and choose Format details to see which profile parsed the file and how many records it read. Pick a different profile and choose Reparse as new tab to keep the original tab available.

Create a custom log format profile

Open Settings › Reading logs › Log formats. Choose New profile or select a built-in profile and choose Duplicate to edit.

Map a CSV or TSV file

  1. Choose Set up CSV / TSV. Use Current tab or paste the original file contents under Paste source.
  2. Pick the delimiter and indicate whether the first row contains field names. Choose Read columns.
  3. Map time, level, and message to their roles. Add request_id and duration_ms as extra columns.
  4. Choose Preview mapping to check the parsed rows, then Save profile. Apply it to an open file from Format details.

Map custom JSON fields

With a JSON Lines profile, assign your source keys to roles such as timestamp, severity, and message. Add fields you want to see as columns and use Severity mapping if your logger uses its own level names.

Build a parser from a sample line

For custom text logs, paste a representative line and assign roles to its pieces. Use these columns generates a record regex you can edit. Save it and use Export current… to share the profile.
