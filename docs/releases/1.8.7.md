# Indagium 1.8.7

Compared with 1.8.6, Indagium 1.8.7 adds a direct device-reproduction workflow alongside its Android log analysis tools.
Connect an Android device by USB or Android 11+ Wireless debugging, capture logcat and screen video
in one session, investigate the live log, mark issues, and export a portable ZIP. Reopening the ZIP
verifies its assets and automatically links the included log and video for synchronized review.

Capture starts video recording by default and excludes earlier ring-buffer logs unless requested.
Optional device audio recording requires Android 11+; microphone capture is a separate opt-in.
Snapshots can save a selected range without stopping the capture; **Stop** ends the recording and
**Save ZIP** exports a stopped or recovered session. The archive v3 format uses a flat layout and one
synchronization anchor, with optional notes, markers, screenshots and audio. Timing can be calibrated;
metadata records actual video coverage when it does not span the full log interval. The retained
working session directory is separate from the exported ZIP.

The release also adds a first-run setup assistant, a richer home/recent-files view, importable and
exportable workspace profiles, searchable settings, configurable save folders, and Find across all
lines hidden by filters. Highlighters support matched text or whole-line coloring, improved tag and
message suggestions, and klogg import. Annotation copy/keyboard behavior and date-aware timing for
logs with dates are improved. See the [User Guide](../USER_GUIDE.md) for setup, shortcuts, storage,
capture recovery, and workflow details, and the [capture walkthrough](https://indagium.com/android-logcat-capture/)
for the live workflow.
