# Indagium 1.9.2

Indagium 1.9.2 adds standalone sequence diagrams, a more capable diagram source editor, and lower memory use for inactive log tabs.

## Diagrams

The New tab now has a **Diagrams** tile where you can search your library, switch between **Grid** previews and **List**, and filter diagrams by **No ticket**, **Ticket**, or **All**. Choose **+ New diagram** to create a sequence diagram without opening a log. Ticket diagrams can still open from their saved snapshot when the original log is unavailable.

Diagram layouts are remembered when you close and reopen a diagram, including after restarting the app. The **Editor + diagram** layout places the source editor alongside the preview. New diagrams start in PlantUML; existing diagrams retain their saved dialect, and Mermaid remains available.

See the [sequence diagram walkthrough](https://indagium.com/sequence-diagrams/) for the diagram workflow.

## Diagram source editor

Edit PlantUML or Mermaid with syntax coloring, automatic indentation, and suggestions for keywords and participant names. Use the arrow keys and Enter or Tab to choose a suggestion. Matching block and activation statements are highlighted when the caret is on them.

The editor shows source issues below the text, with fixes for supported problems. The preview follows valid edits and indicates when it is showing the last valid diagram. Selecting a message in the canvas reveals its source line, and moving the caret onto a message highlights it in the diagram.

Use **Cmd/Ctrl+F** to find and replace text, and **Cmd/Ctrl+/** to comment or uncomment selected lines. Canvas and source edits remain undoable.

## Saved filters and memory

When a saved filter has been edited, **Update** saves the draft back to its original filter; the adjacent menu can update another saved filter.

Inactive log tabs can release their loaded data to reduce memory use. Their content loads again when needed.

## Fixes

- Diagrams retain their edits and remain accessible to tools after their log tab is unloaded.
- Diagram fragment headers, notes and activation bars no longer overlap in the affected layouts.
- Editing beside hidden diagram markers no longer removes them accidentally.
- Dictation, proofreading and recording review actions use the currently selected field or row.
- Opening video while a capture preview loads no longer risks freezing the app.
- Long saved-filter names no longer push the Update menu outside the panel.
- Linux `.deb` installations show the Indagium icon instead of the Java icon.
