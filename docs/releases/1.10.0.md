# Indagium 1.10.0

Keep one investigation note across several logs, open more log formats with configurable profiles, and find controls faster in redesigned Settings.

## Shared notes

Use **New ▾ › New shared note…** to pick the log tabs that contribute to one note, or choose **Share this note…** to share an existing note across tabs in your workspace. Use the **Shared · N tabs** badge to manage members and **Open ▾ › Shared notes** to switch between notes.

Citations retain their source file and section. Click **log ↗** to jump back to the cited rows, or use **Reopen** for a closed standalone log. For structured records, use **Add field to notes** or **Add selected fields to notes** to quote just the fields you need. Shared notes are saved with the session and auto-exported to their own files when auto-export is enabled.

See [Shared notes in the User Guide](https://github.com/indagium/indagium/blob/master/docs/USER_GUIDE.md#shared-notes).

## Log formats and profiles

Open JSON Lines, syslog, logfmt, Kubernetes CRI, Apache and Nginx access logs, `dmesg`, CSV, and TSV alongside Logcat and DLT. Indagium detects formats from file content. Use **Format details** in the tab menu to see how a file was read, or choose **Reparse as new tab** to try another profile while keeping the original tab.

In **Settings › Reading logs › Log formats**, create a profile or duplicate a built-in one. Use **Set up CSV / TSV** to map columns from an open file or a pasted sample. Preview the results, associate file extensions, or export profiles to reuse on another machine.

See the [log formats guide](https://indagium.com/log-formats/).

## Structured log records

Expand records in the log or inspect their original fields in **Message details**. Use the **Sections** tile to switch between record groups in metadata JSON. Each section keeps its filters and selection. Sectioned metadata JSON opens as a whole file. Plain-text and Logcat splits preserve the original bytes, while record-aware splits can repeat headers or reformat JSON so each part opens independently.

DLT rows show the session ID when available. Choose **Separate DLT identifiers** from the log toolbar menu to display ECU, APID, and CTID in separate columns.

See [Log formats in the User Guide](https://github.com/indagium/indagium/blob/master/docs/USER_GUIDE.md#log-formats).

## Settings and reading logs

Browse grouped Settings pages or search for a control by name. Press **Cmd/Ctrl+F** while Settings is open to focus its search. **Capture & video** has dedicated pages for Tools, Limits and snapshots, Mark issue, and Video playback.

Under **Log view**, configure the **Error level** highlight globally or override it in a tab's Highlighters. **Log composition** starts collapsed. Choose **Last state** in **Log composition on startup** to restore its previous visibility.

In Notes, use **Alt+Enter** (**Option+Return** on macOS) on a spelling suggestion and choose **Add to vocabulary**. Manage your saved words in **Settings › Notes & writing › Personal vocabulary**.

See [Settings in the User Guide](https://github.com/indagium/indagium/blob/master/docs/USER_GUIDE.md#24-settings).

## Special themes

Try eleven new themes in **Appearance › Theme › Special themes**, including First snow, Cozy Christmas, Retro, Ready prompt, and Coffee bear. Preview light and dark variants after What's New. Use **My tab style** in a theme's tab settings to keep your usual tabs while using its other effects. Set tile and toolbar corners together or independently in **Appearance › Corners**.
