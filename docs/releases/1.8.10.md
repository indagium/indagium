# Indagium 1.8.10

Indagium 1.8.10 adds AI-assisted Android test suites, configurable Find behavior, and a Search step in the setup assistant.

## AI test suites

Create suites of cases with goals, preconditions, agent instructions, shared sequences, suite values, and setup or teardown hooks. Author steps by hand, draft with AI, record a device workflow for review and rewrite, paste log lines as checks, or improve a saved case. Steps can use an AI agent, a tester, a script, or eligible recorded-input replay.

Check log output, script results, and device state directly; add screen or question checks for an optional AI judge, with screenshots and reference logs as examples. Run an agent or external MCP lane on up to four distinct devices at once, then inspect live evidence and saved reports. Compare runs, review agent/judge disagreements and flaky attempts, rerun cases, export reports and evidence, or create issues for local use, Notes, Markdown, or a configured tracker.

## Find and setup

Choose Filtered, Unfiltered, Two searches, Last search mode, or Auto-switch by open view as the default behavior when Find opens. Configure whether `⌘F` / `Ctrl+F` opens Find, Tags, or Regex, whether it also reveals Original, whether new files open with Original, and whether Filtered row selection and Find navigation link across the split view. Two searches keeps independent queries for Filtered and Original.

The setup assistant now includes Search between Folders and Capture. Existing users who completed the earlier wizard see the Search step once with current preferences prefilled; it does not apply a workspace profile automatically. Finishing, skipping, or dismissing the wizard acknowledges the revision. Run setup again from Settings to start from Workspace.
